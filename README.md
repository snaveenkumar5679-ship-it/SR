# SR Library Management System

A browser-based implementation of the supplied Software Requirements Specification.

## Features
- Add and delete books
- View available and issued books
- Search books
- Register and search students
- Issue books to students
- Record returned books
- View library records and dashboard counts
- Persistent local data using browser localStorage

## Run in VS Code
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. No server or database installation is required for this version.

## Files
- `index.html` — user interface
- `style.css` — design and responsive layout
- `script.js` — library management logic and local storage
